# API Arte di Maria

Esta é a API do projeto **Arte di Maria**, desenvolvida com o framework [NestJS](https://nestjs.com/). A aplicação foi estruturada para servir dados ao frontend e permitir integrações futuras com outras plataformas.

---

## 🛠️ Tecnologias utilizadas

- [Node.js](https://nodejs.org/)
- [NestJS](https://nestjs.com/)
- [TypeScript](https://www.typescriptlang.org/)
- [RxJS](https://rxjs.dev/)

---

## 🚀 Como rodar o projeto localmente

1. **Clone o repositório**
   ```bash
   git clone https://github.com/seu-usuario/api-artedimaria.git
   cd api-artedimaria

2. **Instale as dependências**
   ```bash
   npm install
   
3. **Inicie o servidor de desenvolvimento**
   ```bash
   npm run start:dev

4. **A API será iniciada em:**
   ```bash
   http://localhost:3000
